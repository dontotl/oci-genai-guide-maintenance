# 2026-05-18 Guide Update Notes

이 문서는 2026-05-18 최신 가이드 정리 과정에서 확정한 운영 기준입니다.

## 1. CLI probe 공개 범위

- 공개 리포트에는 원본 출력/오류 파일 경로 컬럼을 노출하지 않습니다.
- 보조 연결 확인에서 얻은 내부 식별자 값은 공개 리포트에 적지 않습니다.
- CLI 조회 상태는 성공/실패와 최종 처리 방식만 요약합니다.
- probe 원본 파일은 로컬 검증용이며 `runs/` 아래에만 둡니다.

## 2. 대표 리전 규칙

GenAI, DAC, IaaS, AQUA 비교에는 같은 대표 리전 규칙을 적용합니다.

| 권역 | 대표 리전 |
|---|---|
| 미국 | `us-ashburn-1`, `us-phoenix-1` |
| 유럽 | `eu-frankfurt-1`, `uk-london-1` |
| 한국/일본 | `ap-seoul-1`, `ap-osaka-1` |
| 중동 | `me-dubai-1`, `me-riyadh-1`, `me-abudhabi-1` |

전체 구독 리전 전수조사는 별도 작업으로 다룹니다.

## 3. DAC GPU family 기준

- 3번 DAC GPU family 표는 모든 DAC 모델 목록이 아닙니다.
- DAC unit 이름에서 `A10`, `A100`, `H100`, `H200` family가 직접 확인되는 공개 GPU family 표입니다.
- `LARGE_COHERE_*`, `LARGE_GENERIC_*`, `RERANK_COHERE`, `EMBED_COHERE`처럼 GPU family가 공개되지 않는 unit은 A10/A100/H100/H200 판정에 쓰지 않습니다.
- `openai.gpt-oss-20b`, `openai.gpt-oss-120b`는 dedicated AI cluster hosting은 가능하지만 Oracle 개별 모델 문서 기준 fine-tuning 대상은 아닙니다.

## 4. IaaS / AQUA 해석

- IaaS 표는 대표 리전 `compute shape list`의 shape 가시성입니다.
- shape가 보인다고 즉시 생성 가능한 capacity를 보장하지 않습니다.
- AQUA는 Data Science 문서 기준으로 해석하며, OCI 공식 문서는 AQUA 리전별 실시간 GPU 재고표를 제공하지 않습니다.
- IaaS probe 결과가 비어 있는 리전도 AQUA 실재고 없음으로 단정하지 않습니다.

## 5. Fine-tuning 기준

| 서비스 / 경로 | 기준 |
|---|---|
| OCI Generative AI 관리형 fine-tuning | Oracle 지원 base model만 대상으로 봅니다. |
| OCI Generative AI Imported Models | 직접 fine-tuning이 아니라 import/hosting 경로입니다. |
| 외부 fine-tuned compatible model | import/hosting 가능으로 표현합니다. |
| AQUA | Model Explorer의 `Ready to Fine Tune` 모델을 대상으로 fine-tuning 가능합니다. |
| Data Science Jobs / Notebook | Hugging Face/open model을 self-managed fine-tuning할 수 있습니다. |
| IaaS GPU | VM/BM GPU에서 사용자가 직접 fine-tuning 스택을 운영할 수 있습니다. |
| GenAI DAC | hosting DAC와 fine-tuning DAC를 분리해서 봅니다. |

7번과 8-1의 `파인튜닝 가능` 표시는 신규 설계에서 우선 검토할 현행 모델 기준입니다. `cohere.command-r-08-2024`는 fine-tuning 가능 표기가 있지만 deprecated 모델이므로 핵심 표에서는 제외합니다.
